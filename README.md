# Cooperative multiplayer Snake

🇫🇷 [Version française](readmefr.md)

One snake on a shared screen (PC / TV). Up to **4 players** on their phones:
each one controls **a single direction**.

| Color  | Direction |
|--------|-----------|
| 🟦 Blue   | Up |
| 🟥 Red    | Down |
| 🟨 Yellow | Left |
| 🟩 Green  | Right |

The snake takes the last direction tapped, so players have to coordinate!

## Requirements

- [Node.js](https://nodejs.org) 18 or newer
- All devices (PC and phones) on the **same Wi-Fi network**

## Running the game

```bash
cd snake-coop
npm install      # only once
npm start
```

The terminal prints two addresses: the main display (`http://localhost:3000/`) and the
players' address (`http://192.168.x.x:3000/play`).

1. **Main display**: open `http://localhost:3000/` on the PC (ideally full screen).
2. **Players**: scan the QR code shown on the right of the screen with a phone (or type the `/play` address).
   Each phone automatically gets the first free color.
3. **Play**: click "Play" or press **space** on the main display
   (a tap on a phone also starts the game).
4. Tap your phone's screen to steer the snake in your direction.
   It grows when it eats apples and speeds up with every apple.
5. Game over when the snake hits a wall or its own tail: **Play again** (space).

## Difficulty modes

Pick the mode on the main display before starting the game (**Easy** / **Hard** buttons).
The mode can't be changed during a game.

- **Easy** (default): every player keeps their direction for the whole game.
- **Hard** 🔀: on every tap, the snake moves in the direction of the displayed color,
  then the 4 directions are **randomly reshuffled** between the players. Each player sees
  their color change: 1 in 4 chance of keeping the same direction, 3 in 4 of getting a different one.

## Scoreboard

After a game over, the main display shows the **top 10** of the mode that was just played
(Easy and Hard have separate boards). The score of the finished game is highlighted, and shown
below the list if it is outside the top 10.

- Each game gets a **random animal name** (mythological or not, e.g. "Griffin", "Otter").
- The team name can be **changed** from the main display (type in the "Team name" field,
  Enter to save) or from any phone (name field + **Save**), until the next game starts.
  Names are limited to 20 characters.
- Scores of 0 are not recorded.
- Scores are saved in `scores.json` (best 100 per mode) and reloaded when the server starts,
  so they survive a restart. The file is ignored by git: each machine keeps its own scores.
  To reset the scoreboard, stop the server and delete the file.

## Rules

- An immediate U-turn is ignored (up then instantly down does nothing).
- Score = number of apples eaten; the speed increases up to a cap. It is displayed
  in cells per second (from 4.5 at the start to 14.3 at most, reached at 19 apples).
- A 5th person connecting becomes a spectator. A freed spot (disconnected phone)
  is given to the next person who joins.
- Sounds: generated by the main display's browser. Click the page once or press a key
  to enable sound. Phones vibrate on taps and on game over.

## Options

| Variable | Purpose | Default |
|----------|---------|---------|
| `PORT` | Server port | `3000` |
| `PUBLIC_URL` | Address encoded in the QR code (useful if the detected IP is wrong) | `http://<local IP>:PORT` |
| `SCORES_FILE` | Path of the scoreboard file | `scores.json` next to `server.js` |

Example: `PORT=8080 PUBLIC_URL=http://192.168.1.20:8080 npm start`

## Troubleshooting

- **The phone can't connect**: check that it's on the same Wi-Fi (not on mobile data) and that
  the PC firewall allows port 3000 (e.g. Linux: `sudo ufw allow 3000/tcp`).
  Some guest Wi-Fi networks isolate devices from each other.
- **The QR code points to the wrong IP** (VPN, several network cards): start with `PUBLIC_URL`.
- **No sound**: click the main display page to unlock audio.
- **Playing alone**: possible, but you only control one direction. Open several tabs
  on `/play` to try all 4 directions.

## Structure

```
snake-coop/
├── server.js            HTTP + WebSocket server + game loop
├── game.js              pure game logic (movement, collisions, apple)
├── scores.js            persistent scoreboard (JSON file, random animal names)
├── test.js              logic and scoreboard tests (npm test)
├── scores.json          created on the first recorded score (git-ignored)
└── public/
    ├── display.html     main display (canvas, QR code, sounds)
    └── controller.html  player page (full-screen color)
```
